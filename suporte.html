Suporte

Tire suas dúvidas, relate problemas ou envie sugestões para melhorar o CicloDash.

Perguntas Frequentes

Como iniciar um treino?
Ative o GPS, preencha seu perfil (Configurações → Perfil) e clique em "Iniciar". O app começará a rastrear automaticamente.
O app funciona sem internet?
Sim! O GPS e todas as funcionalidades locais funcionam offline. Apenas o download de mapas e a integração com clima precisam de internet.
Como cadastrar minha bike?
Acesse Configurações → Minhas Bikes → Adicionar. Preencha o nome, tipo e peso da bike. Você pode cadastrar quantas quiser.
Meus dados são seguros?
Sim! Todos os dados ficam armazenados apenas no seu dispositivo. Nenhuma informação é enviada para servidores externos.
O que é o gradiente de cores?
A rota é colorida conforme a velocidade: azul (lento) → verde → amarelo → vermelho (rápido). Isso permite visualizar o desempenho no percurso.
Como reportar um bug?
Use o formulário de contato ao lado selecionando "Bug" como tipo. Inclua o máximo de detalhes possível para facilitar a correção.
