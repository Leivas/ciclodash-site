Início / Privacidade

Política de Privacidade

Seus dados são seus. O CicloDash não armazena nada em servidores — tudo fica no seu dispositivo.

Dados 100% locais — Nenhuma informação é enviada para servidores externos. Todos os dados de treino, perfil e configurações ficam armazenados apenas no seu dispositivo.

Coleta de Dados

O CicloDash coleta apenas os dados necessários para o funcionamento do aplicativo. Todos os dados são armazenados localmente usando o Room (banco de dados SQLite).

  • Dados de localização (GPS): Usados exclusivamente para rastrear sua rota, calcular velocidade, distância e elevação durante o treino.
  • Perfil do usuário: Peso, altura, idade e frequência cardíaca máxima. Usados para cálculos de desempenho e calorias.
  • Dados das bicicletas: Nome, tipo e peso. Armazenados para associar a cada treino.
  • Histórico de treinos: Rotas, velocidades, cadência, FC, potência e demais métricas.

Segurança

O CicloDash não transmite dados pela rede. Tudo fica no seu dispositivo, criptografado pelo sistema Android. Nenhum dado é compartilhado com terceiros, anunciantes ou serviços de análise.

Permissões

O app solicita as seguintes permissões para funcionar corretamente:

Permissão Uso
GPS / Localização Rastreamento em tempo real durante o treino
Armazenamento Salvar mapas offline e exportar GPX
Bluetooth Conexão com sensores (FC, Potência, Cadência)

Seus Direitos

Como todos os dados estão no seu dispositivo, você tem controle total sobre eles:

  • Acesso: Visualize todos os seus treinos e dados no app.
  • Correção: Edite seu perfil e configurações a qualquer momento.
  • Exclusão: Remova treinos individuais ou limpe todo o histórico.
  • Exportação: Em breve, exporte seus dados em GPX.

Retenção de Dados

Os dados são mantidos no dispositivo até que você os exclua manualmente. Não há prazo de retenção imposto pelo app.

Contato

Se tiver dúvidas sobre esta política de privacidade, entre em contato pelo formulário em nossa página de suporte.
